[1] 프로젝트 한 줄
한국·미국 주식에서 "월봉 10이평 돌파" 매수·매도 대상을 보여 주고, 크게 벌 돌파에 높은 점수를 매기는 웹사이트(비공식 개인 프로젝트). 사용자의 영상 강의 기반 규칙입니다.
- 매수: 전달 종가 <= 전달 10이평 이고 이번 달 최근 종가 > 이번 달 10이평
- 매도: 전달 종가 >= 전달 10이평 이고 이번 달 최근 종가 < 이번 달 10이평
- 10이평 = 최근 10개월 월말 종가 평균, 이번 달은 가장 최근 거래일 종가

[4] 사용자 작업 방식 (꼭 지킬 것)
- 한국어, 짧고 바로 쓸 수 있게. 숫자는 표로. 남에게 설명할 글은 세부 수치를 뺀 불릿으로. 사용자는 코딩 전문가가 아니라서 용어(예: 릿지 회귀, 나무 모델)는 쉬운 말로 설명해 달라고 자주 요청합니다.
- 폰으로 작업할 때가 많음 → 코드는 복붙하기 좋은 풀코드로(특히 Apps Script, bat). 터미널 명령은 한 줄씩 나눠서(여러 줄을 한 번에 붙여 넣으면 Git Bash에 ^[[200~ 같은 글자가 끼어 깨짐).
- 디자인 변경은 미리보기 이미지를 먼저 보여 주고 확인받기.
- 오래 걸리는 작업은 전체 기준 진행률(0%→100%)로, 단계가 끝날 때마다 "무슨 단계 끝 / 전체 n/N / 현재 시각 / 100% 예상 시각" 알림. 일이 늘면 전체 단계를 늘려서 계속(0%부터 다시 금지).
- 실험은 끝까지: 시험할 수 있는 건 다 해 보고 수치가 가장 좋은 쪽으로. 같은 데이터로 비교해야 같은 기준. 사용자가 "증명해 달라"고 한 뒤에 실제 실행합니다. 탈락한 실험은 NOTES.md에 남겨 반복하지 않음.
- 평가 기준은 월 100만원 적립 시뮬레이션(연도별 수익률·누적, 비용·세금 반영). 건별 평균 수익은 쓰지 않음(보유 기간 무시) — 사용자가 직접 정한 기준입니다.
- 좋은 숫자가 나오면 먼저 의심하고 원인을 찾을 것(미래 정보 새기, 데이터 오류, 과적합). 오류를 발견하면 숨기지 말고 바로 알릴 것.
- main 반영은 "올려" 확인 후에만. 강제 push·커밋 기록 다시 쓰기 금지(PC에서 만든 커밋은 사용자 것이라 "Unverified" 알림이 와도 고치지 않음).
- 개인정보·키·시트 링크는 저장소와 외부 요청에 넣지 않음.
- 크레딧·토큰을 아낌: 긴 출력은 파일로 돌리고 필요한 부분만 읽기, 같은 파일 반복해서 읽지 않기.

[5] 환경·도구
- PC: Windows + Git Bash(UCRT64), Node 18+. 학습·시뮬레이션은 사용자가 bat(tools/learn/run_learn.bat)으로 직접 돌림(토큰 0). Claude는 코드 수정과 결과 분석만 하고, 돌려야 하면 "bat을 돌려 주세요"라고 안내. 꼭 Claude가 돌릴 때는 `tools/learn/run.sh --yes > tools/learn/data/run.out 2>&1`로 출력을 파일로.
- run.sh 진행 표시: `○○ 진행중 · N% 완료 · 경과 m분 · 100% 예상 HH:MM`, 단계 끝 줄 `■ 단계 (n/N) 끝 · 지금 HH:MM · 시작 후 m분`. Git Bash에서 TZ=Asia/Seoul은 안 먹혀 UTC가 나옴(쓰지 말 것). 새 단계를 추가하면 plan.js의 names와 run.sh의 mark도 같이 추가.
- 클라우드 Claude(claude.ai/code): 외부 사이트 접속이 환경 설정의 허용 목록으로 제한됨(네이버·야후·FRED·apix 등을 환경 "stock-score"에 추가해 둠). 한 줄 명령으로 확인 가능한 것만 시험하고, 전체 계산은 PC에서.
- apix(제3자 Claude API 판매처)를 PC의 Claude Code에 연결해 쓴 적 있음: 크레딧 $50, 기본 그룹(1배)에서 claude-opus-5-5, claude-sonnet-5, claude-haiku-4-5 등 가능, claude-sonnet-5-5는 15배 그룹 전용이라 쓰지 않음. 키는 사용자 PC의 ~/apix-key.txt(저장소 밖), 연결은 바탕화면의 claude-apix.bat. 요청마다 apix 사이트 Usage Logs에서 비용 확인. (새 Claude Pro를 쓰면 이 부분은 필요 없음)
- 구글 시트 "stock-score"(탭: 한국, 미국, 로그)와 Apps Script 웹 앱이 사이트의 데이터 원천. 웹 앱 URL은 index.html의 API 상수에 있음. Apps Script 수정 후에는 배포 관리 → 연필 → 새 버전으로 배포(URL 유지), 웹 앱 액세스는 "모든 사용자".

[6] 데이터 (모두 무료·키 없음) — 자세한 주소표는 docs/NOTES.md
- 한국 시총 순위·종목: 네이버 증권 / 한국 월봉: 야후(.KS/.KQ, 15:30 정규장 종가. 네이버 가격에는 시간외 단일가가 섞임)
- 미국 시총 순위: 네이버 해외주식(나스닥·뉴욕·아멕스) / 미국 월봉: 네이버 → 야후 예비. 나스닥 API는 구글 서버에서 멈춰서 쓰지 않음.
- 거시 지표: 미국 연준(FRED) CSV(키 없음). 야후 월봉은 반드시 period1=2000&interval=1mo로 받을 것(range=max는 오래된 종목을 3개월 간격으로 줘서 10이평이 틀어짐 — 이미 한 번 사고가 났음).

[7] 점수 연구 — 현재 상태
- 목표값: log(1+수익), 수익 = 매수 신호 달 종가 → 매도 신호 달 종가(아직 보유 중이면 12개월 이상 된 것만 지금까지 수익). 릿지 회귀, 시간 순서 검증(해마다 그해 1월 1일에 알던 정답만 사용). 학습 사례는 2008-12 이후(버냉키 QE1 이후, 사용자 지정).
- 모델: A 가격만(35지표) / B 가격+거시 / C 가격+기준금리 변화 / D 시장 요소만 / E 종목 요소만(달 평균 뺀 수익) / F 가격35(달 평균 뺀 수익).
- 학습 대상 범위는 사이트와 같게: 코스피 300 + 코스닥 200 + 미국 500(시총 순, 1_lists.js). 넓게 보려면 WIDE=1. 사이트 숫자(Code.gs의 KOSPI_N, KOSDAQ_N, US_N)를 바꾸면 여기도 같이 바꿀 것.
- 비용·세금(costs.json): 한국 수수료 0.015%/편도, 거래세 연도별(2012~18 0.30% ... 2025 0.15%, 2026 0.20% — 2019~2026 값은 기억 기준이라 사용자 확인 필요), 미국 수수료 0.25% + 환전 0.1%/편도, 미국 양도세 22%(그해 실현 순이익에서 250만원 공제, 12월 말 납부로 단순화).
- 지금까지 알게 된 것(요약)
  * 같은 달 안에서 점수 상위 20%를 고르면 달 평균보다 약 +2.7~3.0%p, 189개월 중 70~77%에서 이김(모델 간 차이 작음).
  * 거시 지표는 같은 달 모든 종목에 같은 값이라 목록 순서를 못 바꿈 → "시장 분위기 표시"용. 기준금리 변화(모델 C)가 타이밍에 가장 좋았음.
  * 점수는 거래대금 작은 종목을 선호하는 경향(생존 편향·호가 간격 때문에 백테스트가 과장될 수 있음). 대상이 "지금 상장된 시총 상위"뿐이라 망한 종목이 없음(생존 편향).
  * 이전 범위(전 종목) 기준 A 상위10이 연 +28.8%였지만 2020년 한 해(+231.5%)에 크게 의존(2020 제외 +20.3%).
- PC의 Claude Code가 최근 올린 실험(내가 직접 검증하지 않았음, result/backtest.txt에 있음): 유동성 필터, 한국/미국 분리, 익절(tp 배수·당월/다음달/트레일), A1~A9 N별 비교, 매도 유예(grace 1~4달), ML 조건부 유예.
  * 사이트 범위 결과 예: 전부 균등 연 +15.2%, A 상위10 +23.0%, 코스피 +7.0%, S&P500(원화) +13.5%. 유동성 상위 50%/25%만 고르면 오히려 +17.1%/+12.2%로 하락. 익절 "A5 tp2x 트레일"이 연 +34.9%로 가장 높게 나옴.
  * 주의: 익절 배수·유예 기간·N을 같은 데이터에서 여러 개 시험해 가장 좋은 걸 고른 것이라 과적합 위험이 큼. 앞쪽 연도로 고르고 뒤쪽 연도로 검증하는 확인이 필요. CLAUDE.md에는 아직 이 실험들이 반영되지 않았음.

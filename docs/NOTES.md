# 주식 점수 사이트 — 작업 안내 (새 세션은 이 파일부터 읽음)

한국·미국 주식에 점수를 매겨 보여 주는 웹사이트. 사이트는 GitHub Pages(main에 push하면 1~2분 안에 배포).
점수 기준은 사용자가 차차 설명함 → 정해질 때마다 아래 "점수 기준"에 적어 둘 것.

## 소통·작업 방식 (사용자 선호)

- **한국어**로, 짧고 바로 쓸 수 있게. 숫자는 표로. 다른 사람에게 설명할 글은 세부 수치를 뺀 불릿으로.
- 폰으로 작업할 때가 많음 → 코드는 **복붙하기 좋은 풀코드**로(특히 Apps Script). 파일로 주지 말 것.
- 디자인 변경은 **미리보기 이미지를 먼저** 보여 주고 확인받기.
- 오래 걸리는 작업은 **전체 작업 기준 진행률**로, **단계가 끝날 때마다** "무슨 단계 끝 / 전체 n/N단계 / 현재시각(KST) / 100% 예상 시각"을 알림. 계획에 일이 추가되면 전체 단계 수를 늘려서 계속 보여 줌(끝나고 0%부터 다시 시작 금지).
- 실험은 **끝까지 물고 늘어짐**: "다른 아이디어는 없어?"에 대비해 시험할 수 있는 건 다 해 보고, 수치가 가장 좋은 쪽으로. 실험을 다 끝낸 뒤 코드를 한꺼번에 고침.
- **같은 데이터로 비교해야 같은 기준.**
- **main 반영은 사용자가 "올려"라고 확인한 뒤에만.** 작업 브랜치에는 자유롭게 커밋·push.
- 사용자는 시트 스크린샷으로 실시간 상황을 공유함. 특이한 행을 함께 짚어 줄 것.

## 꼭 지킬 규칙

- Apps Script는 수정 후 **배포 → 배포 관리 → 연필(수정) → 새 버전**으로 배포해야 웹 앱 URL이 유지됨. "새 배포"를 만들면 URL이 바뀜.
- 개인정보(이메일 등)·API 키는 저장소·사이트 코드에 넣지 않음. 키는 Apps Script의 스크립트 속성에만.

## 메인 알고리즘 — 월봉 10이평 돌파 (출처: 사용자가 준 차트 강의 영상)

- 10이평 = 최근 10개월 월말 종가 평균. 이번 달은 **가장 최근 거래일 종가**를 그 달 종가로 씀(매일 갱신).
- **매수 대상**: 전달 종가 ≤ 전달 10이평 그리고 최근 종가 > 이번 달 10이평.
- **매도 대상**: 전달 종가 ≥ 전달 10이평 그리고 최근 종가 < 이번 달 10이평.
- 예: 11월 23일이면 10월 말 기준 아래 → 11/23 종가 위 = 매수. 11월 1일 장 마감 뒤면 1일 종가로 판단.
- 1차 화면: 매수·매도 대상을 각각 띄우고 **시가총액 큰 순** 정렬. 점수는 나중에(사용자가 기준 설명 예정).

## 구조

- `apps-script/Code.gs`: 시트에 붙여 쓰는 Apps Script(저장소 사본이 원본). 사용자에게는 풀코드로 줌.
  - `setup()` 탭(한국·미국·로그) 만들기 + 매일 자동 갱신 예약(한국 17:05, 미국 07:05 KST)
  - `updateKR()` 네이버 시총 순위(코스피 300·코스닥 200, ETF·ETN·우선주 포함) → **야후 월봉(.KS/.KQ, 15:30 정규장 종가)**, 없으면 네이버 월봉 → 신호
  - **네이버 한국 가격(fchart·일봉·closePrice)엔 16:00~18:00 시간외 단일가가 섞임**(예: 삼성전자우 11/20 실제 144,300 ↔ 네이버 142,400). 그래서 한국 월봉은 야후가 기본. 바꾼 뒤 신호 8종목이 달라짐.
  - 야후 월봉은 이번 달 봉 + '오늘 하루치' 점이 따로 옴(오늘 점은 시가 0 등). 합칠 때 종가=뒤, 시가=앞, 고저=최대·최소(0 제외), 거래량=큰 쪽.
  - `updateUS()` 네이버 해외주식 시총 순위(나스닥·뉴욕·아멕스 합쳐 상위 500, 한국어 이름, ETF 없음) → 네이버 월봉(실패 시 야후 월봉) → 신호
  - `doGet` 사이트용 JSON(매수·매도만, `?all=1`이면 전체). 매수·매도 종목은 `차트` 열(N)에 최근 45개월 월봉 [[YYYYMM,시가,고가,저가,종가,거래량],…] JSON을 저장해 같이 내려줌(응답 약 450KB). 갱신 시각은 R1.
  - 실측: 한국 500종목 약 40초, 미국 500종목 약 30초.
  - **나스닥 API(api.nasdaq.com)는 구글 서버에서 응답 없이 멈춤 → 6분 제한 초과(2026-11-23 실제 발생).** 쓰지 말 것.
- **구글 시트** "stock-score"(사용자 드라이브. 공유 링크·ID는 공개 저장소에 적지 않음): 탭 `한국`, `미국`(열: 시장·코드·이름·종류·시총·시총단위·최근종가·10이평·전달종가·전달10이평·신호(매수/매도/위/아래)·기준일·개월수, O1=갱신 시각), `로그`.
- **사이트(GitHub Pages)** `index.html` 한 파일: 웹 앱(…/macros/s/AKfycbwneUZ…/exec, `API` 상수)에서 JSON을 받아 한국/미국 탭 × 매수/매도 목록, 시총 순. 매수 빨강·매도 파랑, 다크 모드 지원, 고른 탭은 localStorage에 기억.
  - 월봉 차트: 목록 위에 sticky로 고정, 종목을 누르면 차트만 바뀜(첫 종목 기본 선택). 캔버스 직접 그림(라이브러리 없음): 최근 36개월 캔들(상승 빨강·하락 파랑) + 월 10이평(주황) + 거래량.
  - 웹 앱 액세스는 반드시 **"모든 사용자"**(로그인 불필요). "Google 계정이 있는 모든 사용자"면 로그인 화면이 와서 사이트가 데이터를 못 받음.

# 매수 신호 학습·시뮬레이션 — PC에서 돌리기 (Git Bash)

필요: Node 18 이상, Git Bash. 추가 설치 없음. (더블클릭: `run_learn.bat`)

```bash
cd stock-score
git pull
tools/learn/run.sh          # 0% → 100%, 끝나면 묻지 않고 결과를 올린 뒤 Enter로 닫기
```
- 단계(8): 종목 목록 → 월봉·거시 받기 → 매수 신호·지표 → 학습 → 여러 실험 → 타이밍·종목 점검 → 월 100만원 적립 시뮬 → 올리기
- 받은 월봉은 `tools/learn/data/raw2`에 남아 다시 돌리면 빠름. 끊겨도 이어서.
- 시험으로 조금만: `LIMIT=600 tools/learn/run.sh` (안 올림). 안 올리려면 `--no-push`(기본은 묻지 않고 올림).
- 결과 `tools/learn/result/`: report(학습) · explore(실험 순위) · check(타이밍 vs 종목 고르기) · backtest(적립 시뮬) · weights.json
- 대상 범위는 **사이트와 같게**(코스피 300 + 코스닥 200 + 미국 500). 넓게 보려면 `WIDE=1 tools/learn/run.sh`(한국 전 종목 + 미국 3000).
- 비용·세금은 `costs.json`에서 고침(한국 수수료·연도별 거래세, 미국 수수료·환전·양도세).
- 정답 = 매수 신호 달 종가 → 매도 신호 달 종가 수익(log). 학습은 해마다 그해 1월 1일에 알던 정답만. 기간 2008-12 이후.
- 야후 월봉은 `period1=2000&interval=1mo`(range=max는 오래된 종목을 3개월 간격으로 줘서 못 씀). 간격 검사 통과분만 저장.
- 주의: 지금 상장·시총 상위 종목만 대상 → 상장폐지 종목 없음, 결과 과장 가능. 방법끼리 비교가 더 믿을 만함.

## 시험 목록 전체 묶음 (`exp.sh`, AD9)
`stock_exp.bat`(= `run_exp.bat`) → `git pull` 후 `tools/learn/exp.sh`. 현재 `data/events.csv`(마지막 stock_learn 결과, 시총 기준)로 묶음 1~10을 차례로 돌려 결과를 `data/exp_result.txt`에 이어 붙이고 클립보드에 복사(30~60분).
- 일부만: `tools/learn/exp.sh 1 5`(묶음 1·5) · 빠르게: `AD8_HALVES=3 tools/learn/exp.sh` (절반 되풀이 횟수, 기본 6)
- 묶음: 1 매수 신호 · 2 순위 · 3 점수 모델 · 4 비중·구성 · 5 매도 · 6 자금·비용·세금 · 7 체결·시점 · 8 종목 범위 · 9 검증 · 10 다른 전략과 비교 (코드 `ad9.js`, 엔진 변경 `7_backtest.js`)
- 한 시험이 오류여도 나머지는 계속 돌고 그 줄 끝에 `[오류: ...]`가 붙음. 묶음 전체가 죽으면 `data/exp_run_<n>.log` 마지막 줄이 결과 파일에 적힘.
- 각 시험 표 열: 전체·앞쪽(~2019)·뒤쪽(2020~) 연평균, 최대 낙폭, 절반 되풀이(종목을 무작위 절반씩 6번 뽑아 기준과 짝 비교한 평균·표준편차·이긴 비율). 9·10과 2의 25번은 따로 `## ...` 보고.
- 아직 안 한 것(일봉·새 자료·이평 길이 바꾸려면 events 다시 만들기가 필요): 17·18 EMA/이평 길이(`MA_N=20`으로 3_build 다시), 41 순위 학습, 42 확인 시점 지표 재계산, 49·86·118·122 업종·S&P 편입 이력, 79~81 일봉 판단, 108 지수에 같은 규칙, 112~121 새 자료(공매도·수급·실적 등).

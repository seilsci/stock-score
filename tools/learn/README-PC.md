# 매수 신호 학습 — PC에서 돌리기 (Git Bash)

필요: Node 18 이상(https://nodejs.org LTS), Git Bash. 추가 설치 없음.

```bash
cd stock-score        # 저장소 폴더
git pull
tools/learn/run.sh    # 0% → 100%, 끝나면 "결과를 올릴까요? (y/N)"
```

- 한 줄짜리 진행 표시: `○○ 진행중 · N% 완료 · 경과 m분 · 100% 예상 HH:MM`
- 단계: 종목 목록 → 월봉 받기(가장 오래 걸림) → 매수 신호·정답·지표 → 학습·검증 → 올리기
- 끊기면 그냥 다시 실행: 받은 월봉(`tools/learn/data/raw`)은 건너뜀
- 시험으로 조금만: `LIMIT=60 tools/learn/run.sh` (안 올림)
- 묻지 않고 올리기: `tools/learn/run.sh --yes`
- 올리면 `tools/learn/result/weights.json`, `report.txt`만 커밋·push(사이트 코드는 안 건드림)

## 무엇을 하나
- 대상: 한국 전 종목(코스피·코스닥, ETF·ETN 포함) + 미국 시총 상위 3000(`US_N`으로 바꿈)
- 월봉: 야후 최대 기간(한국은 15:30 정규장 종가), 지수 ^KS11 ^KQ11 ^GSPC
- 학습 사례: **2008-12 이후** 매수 신호만(버냉키 QE1 2008-11-25 이후. `MIN_YM`으로 바꿈)
- 정답: 매수 신호 뒤 12개월 동안 월말 종가가 모두 10이평 위면 1(갈 돌파), 아니면 0
- 지표 25개(돌파한 달 기준): 10이평과 거리·기울기, 최근 24개월 오간 횟수·아래 있던 기간, 12·24개월선,
  거래량(직전 12개월 대비), 몸통·꼬리·폭, 1·3·12개월 수익, 전고점 대비, 변동성, 지수 위치·기울기·12개월 수익, 미국 여부, ETF 여부
- 학습: 로지스틱 회귀. 시간 순서 검증(그해 1월 전에 정답이 확정된 신호로 학습 → 그해 신호로 시험)
- 주의: 지금 상장된 종목만 받음(상장폐지 종목 없음) → 결과가 실제보다 조금 좋게 나올 수 있음
